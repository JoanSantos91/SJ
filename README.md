
## Fotos
Las fotos originales están en `assets/moments/`.
`assets/login_cover.jpg` controla la foto del acceso.
`assets/home_cover.jpg` controla la foto superior de Inicio.

La subida de fotos de bb funciona localmente en esta versión. En la versión final se conectará a Supabase para persistencia en la nube.
